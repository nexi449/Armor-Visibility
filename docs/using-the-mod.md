# Open the settings

Armor Visibility has no keybind or separate inventory item. Open its settings in either of these ways:

- **Pause menu:** click the Armor Visibility icon beside the Statistics button.
- **Mod Menu:** open the mod list, select Armor Visibility, and choose its configuration button. Mod Menu is optional.

Changes take effect immediately and are saved to the config file. Click **Done** to return to the screen you came from.

For an explanation of every toggle, see [Configuration](configuration.md).
