# Open and use the settings

Armor Visibility has no keybind or separate inventory item. Open its settings in either of these ways:

- **Pause menu:** click the Armor Visibility icon beside the Statistics button.
- **Mod Menu (Fabric/Quilt):** open the mod list, select Armor Visibility, and choose its configuration button. Mod Menu is optional.
- **NeoForge:** open Armor Visibility's configuration from the mod list.

The screen shows a player preview alongside controls for each armor slot's opacity and glint, the offhand opacity, and global visibility options. Changes are saved automatically.

Use the five preset cards to save and recall configurations: left-click an empty card to save, left-click a saved card to load, and right-click a saved card to delete it. Hover over a card to see what it contains. Click **Done** to return to the previous screen.

For details on each setting, see [Configuration](configuration.md).
